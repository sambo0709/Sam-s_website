Building Pricing Tool — ASP.NET Core Web App

The Building Pricing Tool turns building dimensions and features into a detailed cost estimate. The ASP.NET Core Razor Pages interface calculates floor, wall, roof, material, labor, and total costs, then exports project data for an automated 3D-modeling workflow.

Technologies Used

  • C# and ASP.NET Core
  • Razor Pages and .NET
  • Python
  • Autodesk Fusion 360
  • HTML and CSS
  • CSV data exchange

Features

  • Accepts building dimensions, roof pitch, door count, and window count
  • Calculates floor, wall, and roof areas along with material and labor costs
  • Exports project inputs and estimates to CSV
  • Feeds a C# → CSV → Python → Fusion 360 pipeline
  • Generates a corresponding 3D building model from web-form inputs

Technical Architecture

C# object models hold the building specifications and pricing data while Razor Pages handles the form workflow and results display. The application writes the project data to CSV, which a Python script transforms into parameters for Fusion 360. This connects the browser-based estimate to a generated 3D representation of the same building.

What I Learned

This project strengthened my experience with ASP.NET Core, object-oriented C#, form design, and data exchange between different systems. It also taught me how to extend a web application beyond the browser by connecting its output to Python automation and CAD modeling software.
